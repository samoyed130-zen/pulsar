# PULSAR 🌀

PULSAR は、ブラウザ上で動く **メガデモ**（自動再生されるビジュアルデモ）です。
ただ眺めるだけの作品ではなく、**画面に触れるとそのままゲームになります。**

👉 [こちらから見る / 遊べます](https://samoyed130-zen.github.io/pulsar/)
👉 [単体テストの実行結果はこちら](https://samoyed130-zen.github.io/pulsar/test.html)

---

## 作品概要

- 起動すると5つの場面が約53秒で一周する**デモ**が流れ続けます（タイトル画面がそのままアトラクトモードになっています）。
- **START を押す、または画面のどこかに触れる**と、そのままトンネルを操縦するゲームへ切り替わります。
- リングの切れ目を通り抜けると **コンボ** が伸び、ゲージが溜まるほど **走行速度・曲の厚み・曲のテンポ** が同時に上がります。
- ぶつかっても終わりません。画面が赤く弾けて減速し、そのまま走り続けます。
- 持ち時間は3分。使い切るとリザルトが表示され、もう一度遊ぶかデモに戻るかを選べます。

### 収録エフェクト

| 場面 | 内容 |
| --- | --- |
| STARFIELD | 星が手前へ流れる。拍に合わせて加速 |
| PLASMA | 正弦波を重ねた色の場。画面全体が脈打つ |
| TUNNEL | **触れると操縦できる区間。**背景はレイマーチングによる立体描画 |
| METABALLS | 距離場をしきい値で切った、にじむ塊 |
| COPPER BARS | 横帯の走査と、波打つ横スクロールテキスト |

## 操作方法

- **画面をなぞる / マウスを動かす** : 指の向きへ自機が回り込みます。トンネルの中心から見た方向が、そのまま自機の位置です。
- **← → キー** : 自機を左右に回します。
- **触れずに待つ** : 自動操縦に戻り、デモとして流れ続けます。

## 工夫した点

- **レイマーチングによる立体背景** — 曲がりくねった筒の内壁、一定間隔で並ぶ輪、回転する八面体を距離関数で表現し、光線を1ピクセルずつ進めて描いています。走行距離をそのままカメラ位置にしているため、手前のリングと奥の構造物が同じ速さで流れます。
- **距離関数の最適化** — 当初は空間を回転させていましたが、**回転しても中心軸からの距離は変わらない**ため、その計算は不要でした。代わりに筒の中心を奥行きに応じてずらすことで見た目を維持しつつ、9.86ms → 3.79ms/フレームまで短縮しています。
- **音をその場で合成** — 音源ファイルを一切使わず、Web Audio API でキック・ハイハット・ベース・リードを生成しています。コンボゲージに応じて鳴る層が増え、走行速度に応じてテンポも変化します。
- **映像と音の同期** — 拍を時刻からの割り算ではなく積算で求めているため、テンポが変わっても拍の位置が飛びません。
- **単体テスト** — 当たり判定・タイムライン・難易度の条件などを 123 件のテストで検証しています。テストは実際に、角度の境界判定が浮動小数の誤差で裏返るバグを検出しました。

## 開発環境

- HTML / CSS / JavaScript（Vanilla）
- Canvas 2D API / Web Audio API / Pointer Events API
- GitHub Pages で公開
- **外部ライブラリは一切使用していません。**（Bootstrap / Tailwind CSS も未使用）

### ファイル構成

```
index.html      画面構成
style.css       スタイル
src/
  mathx.js      純粋関数（角度・補間・当たり判定・時間計算）
  sound.js      Web Audio によるシーケンサ
  game.js       トンネル区間の状態と描画
  scenes.js     各エフェクトとタイムライン
  main.js       描画ループ・シーン管理・入力
test.html       単体テストの実行ページ
test/           テストランナーとテスト本体
```

## 単体テスト

Node.js が無い環境でも確認できるよう、**依存ゼロのテストランナーを自作**しています。

- ブラウザ : [test.html](https://samoyed130-zen.github.io/pulsar/test.html) を開くだけで実行されます
- コマンドライン : `node test/run-node.js`

どちらも同じ 123 件のテストを実行します。

## 使用素材とライセンス

| 種類 | 内容 |
| --- | --- |
| 画像・写真・イラスト | なし |
| 音楽・効果音 | なし（すべてその場で合成） |
| フォント | なし（閲覧環境のシステムフォントを指定しているのみ） |
| 外部ライブラリ | なし |
| コード | すべて自作 |

外部素材を一切含まないため、著作権上の問題は発生しません。
また、サーバー通信・Cookie・外部への接続を一切行いません。
