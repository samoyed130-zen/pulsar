あそびかた

これは自動で流れ続けるデモです。画面に触れると、そのままゲームになります。

操作

画面をなぞる 指（またはマウス）の向きへ自機が回り込みます。トンネルの中心から見た方向がそのまま自機の位置です。
← →キー 自機を左右に回します。キーボードでも遊べます。
触れずに待つ 自動操縦に戻り、デモとして流れ続けます。
スマートフォン 縦持ちを推奨します。 自機は画面中心のまわりを回るため、縦持ちの方が指の動きと自機の動きが一致します。
全画面で遊ぶ メニューの フルスクリーン で画面いっぱいになります。 iPhone の Safari はこの仕組みに対応していないため、 共有 →「ホーム画面に追加」をして、そこから開いてください。 アドレスバーもツールバーも消えた状態で遊べます。

キーボード

← → 自機を回す。押している間はキーが優先され、離してもその場に留まります。 もう一度マウスを動かすと、そちらへ主導権が戻ります。
P / Spaceメニューの開閉（走行中は一時停止）
H / ?この説明を開閉
M音のあり・なし
B立体背景のあり・なし
Rなめらかな塗りのあり・なし
Fフルスクリーンの切り替え
S操作感度を次の段階へ
Tタイトルへ戻る（確認あり）
1〜6タイトルで、そのステージから開始
Enterリザルトでもう一度あそぶ / 確認に「はい」
Esc開いているものを閉じる

ルール

  • 迫ってくるリングには切れ目があります。そこを通り抜けてください。
  • 切れ目には虹色の立方体が浮かんでいることがあります。触れると 持ち時間が4秒延びます。切れ目の端寄りにあるので、安全に抜けるか 時間を取りにいくかの選択になります。
  • 進むほど加速し、リングの間隔が詰まって見えます。
  • ぶつかっても終わりません。画面が赤く弾けて減速し、そのまま走り続けます。
  • 抜けたステージはこの端末に記録され、次回からタイトルで選べます。
  • ステージは全6つ。持ち時間2分のあいだに 800 進むと次へ。 先へ行くほど切れ目が狭く、拾える立体も減り、通路の景色と曲が変わります。
  • 時間切れで終了です。6つすべて抜けられたら踏破。

デモについて

  • 5つの場面が約53秒で一周します。タイトルで画面を押すと、いつでもトンネルの場面へ戻せます。
  • 設定は右上の メニュー にまとめてあります。 走行中に開くと一時停止になり、閉じると数えてから走り出します。
  • ♪ 音 のあり・なし。音源ファイルは使わず、その場で合成しています。 鳴らない場合は端末がマナーモードになっていないかご確認ください。
  • 操作感度 で、指の動きに対する自機の機敏さを 5段階（×1/4 〜 ×4）から選べます。細かく狙うなら遅く、素早く振るなら速く。
  • ガイドサークル で、自機が動く円を常に出せます（既定は なし）。 出していなくても、走り始めの数秒だけは出て静かに消えます。
  • 背景 で、トンネルの立体背景を切り替えられます。 面の数だけ描画に時間がかかるため、動きが重い端末では切ってください。
  • なめらか で、立体背景の塗り方を切り替えられます。 入れているときは、三角形を1画素ずつ塗る自前の描画を使います。
  • 設定初期化 で、保存した設定と開放済みステージを消せます。 APIテスト では、この作品の単体テストをその場で実行できます。
  • 外部ライブラリは一切使っていません。Canvas 2D と Web Audio のみです。
