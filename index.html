あそびかた

これは自動で流れ続けるデモです。画面に触れると、そのままゲームになります。

操作

画面をなぞる 指（またはマウス）の向きへ自機が回り込みます。トンネルの中心から見た方向がそのまま自機の位置です。
← →キー 自機を左右に回します。キーボードでも遊べます。
触れずに待つ 自動操縦に戻り、デモとして流れ続けます。
スマートフォン 縦持ちを推奨します。 自機は画面中心のまわりを回るため、縦持ちの方が指の動きと自機の動きが一致します。

キーボード

← →自機を回す（離したその場に留まります）
P / Space一時停止・再開
H / ?この説明を開閉
M音のオン・オフ
B立体背景のオン・オフ
S感度を次の段階へ
Tタイトルへ戻る（確認あり）
1〜6タイトルで、そのステージから開始
Enterリザルトでもう一度あそぶ / 確認に「はい」
Esc開いているものを閉じる

ルール

  • 迫ってくるリングには切れ目があります。そこを通り抜けてください。
  • 流れてくる光る立体に触れると、持ち時間が5秒延びます。 切れ目の近くに現れるので、避けながら拾ってください。
  • 進むほど加速し、リングの間隔が詰まって見えます。
  • ぶつかっても終わりません。画面が赤く弾けて減速し、そのまま走り続けます。
  • スコアは走った距離です。ベスト記録はこの端末に保存されます。
  • ステージは全6つ。持ち時間2分のあいだに 1000 進むと次へ。 先へ行くほど切れ目が狭く、拾える立体も減り、通路の景色と曲が変わります。
  • 時間切れで終了です。6つすべて抜けられたら踏破。

デモについて

  • 5つの場面が約53秒で一周します。触れるといつでもトンネルへ飛びます。
  • 音は右上のボタンから。音源ファイルは使わず、その場で合成しています。 鳴らない場合は端末がマナーモードになっていないかご確認ください。
  • 感度 ボタンで、指の動きに対する自機の機敏さを 5段階（×1/4 〜 ×4）から選べます。細かく狙うなら遅く、素早く振るなら速く。
  • 背景 3D ボタンで、トンネルの立体背景を切り替えられます。 1ピクセルずつ光線を進めて描いているため、動きが重い端末では切ってください。
  • 外部ライブラリは一切使っていません。Canvas 2D と Web Audio のみです。
